# RudderStack Documentation

> Product documentation for RudderStack, the warehouse-native customer data platform. Covers event collection (SDKs and sources), 200+ destinations, transformations, identity resolution (Profiles), audiences, data governance, monitoring, and the APIs and dashboard that tie it together.

This file is a curated map of the docs for AI agents and assistants. Sections are ordered to follow the product: how data is collected, transformed, resolved, activated, governed, and monitored.

Every link points to the page's clean Markdown source. You can get the Markdown for any docs page by appending `index.md` to its URL — e.g. `.../docs/get-started/overview/` → `.../docs/get-started/overview/index.md`. Start with the sections you need rather than reading the whole file.
